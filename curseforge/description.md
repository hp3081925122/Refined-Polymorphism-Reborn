This port is not made, endorsed, or supported by the original author.

## What it does

When several crafting recipes use the same ingredients, Polymorph can choose which one Refined Storage uses.

- Crafting Grid
- Pattern Grid, only while the pattern type is crafting
- Wireless crafting grids from Refined Storage - Quartz Arsenal. Universal Grid's crafting mode opens that same grid.

The chosen crafting recipe is stored on the pattern as the `refinedpolymorph:polymorph_recipe` data component. If that recipe is missing, pattern resolution falls back to Refined Storage's own match.

## Requirements

- Refined Storage
- Polymorph
- Optional: Refined Storage - Quartz Arsenal

## 功能

多种合成配方用同一组材料时，可以用 Polymorph 选择精妙存储采用哪一个。

- 合成网格
- 样板网格，仅在样板类型为合成时
- Refined Storage - Quartz Arsenal 的无线合成网格。Universal Grid 的合成模式打开的就是这个网格。

选中的合成配方写在样板的数据组件 `refinedpolymorph:polymorph_recipe` 上。组件缺失或配方不存在时，样板解析仍回退到精妙存储自己的匹配。
