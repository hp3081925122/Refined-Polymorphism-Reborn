# Refined Polymorphism 1.21.1 迁移说明

## 来源与协议

- 原作者：90
- 原仓库：https://github.com/62832/RefinedPolymorphism
- 对照版本：0.1.1，Minecraft 1.19.2 / 1.20.1 Forge
- 协议：LGPL-3.0-only。`LICENSE` 必须保持原文，显示名可以改，协议不能改。

显示名是 Refined Polymorphism Reborn。模组 ID 仍是 `refinedpolymorph`，包名仍是 `gripe._90.refinedpolymorph`。

## 依赖

- Polymorph 1.2.0+1.21.1
- Refined Storage 2.0.9
- 可选：Refined Storage - Quartz Arsenal 1.0.8。没有安装时不加载对应 Mixin，也不写入 `neoforge.mods.toml`。
- 依赖版本下限是 `0.0.1`，不写上限。

## 行为对应

| 1.20.1 | 1.21.1 |
| --- | --- |
| `GridNetworkNode.onCraftingMatrixChanged` 改走 Polymorph | `RecipeMatrix.loadRecipe` 在绑定了方块实体或玩家后改走 Polymorph |
| 选择配方后写回 `currentRecipe` 并刷新矩阵 | 选择后清空当前配方再 `updateResult`，避免仍匹配旧配方时不刷新 |
| 精确样板把配方 ID 写入 `polymorphRecipe` 标签 | 合成样板写入 `refinedpolymorph:polymorph_recipe` |
| `CraftingPatternFactory` 优先用标签里的配方 | `PatternResolver.getCraftingPattern` 优先用数据组件里的配方 |
| 合成网格界面挂 Polymorph 按钮 | `CraftingGridScreen` 和 `PatternGridScreen` 挂按钮；样板网格只在合成模式显示 |
| Refined Storage Addons / Reborn Storage 无线合成网格 | 这两个模组没有 1.21.1 版本。无线合成网格在 Quartz Arsenal |
| Universal Grid 自己的无线合成网格 | 1.21.1 的 Universal Grid 合成模式直接打开 Quartz Arsenal 的无线合成网格 |

样板解析在组件缺失或配方 ID 无效时，仍回退到 Refined Storage 原来的 `getRecipeFor`。
