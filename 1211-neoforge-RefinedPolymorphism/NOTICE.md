## Modifications

- The loader target is changed from Minecraft 1.19.2 / 1.20.1 Forge to Minecraft 1.21.1 NeoForge.
- The display name is `Refined Polymorphism Reborn`. The mod id stays `refinedpolymorph`.
- Crafting Grid and Pattern Grid recipe selection now targets Refined Storage 2.
- The chosen crafting recipe is stored in the `refinedpolymorph:polymorph_recipe` data component. The original 1.20.1 version stored the same choice as the `polymorphRecipe` item tag.
- Wireless crafting uses Refined Storage - Quartz Arsenal. Refined Storage Addons and Reborn Storage have no 1.21.1 release; Universal Grid's crafting mode opens the Quartz Arsenal grid.
- The project remains LGPL-3.0-only.
